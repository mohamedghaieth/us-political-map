# الخريطة السياسية للولايات المتحدة الأمريكية

تطبيق ويب تفاعلي (عربي RTL) لاستكشاف حكام الولايات ومجلس الشيوخ ومجلس النواب (حتى مستوى الدائرة) وانتخابات 2026 والسيناريوهات.
الواجهة: React + TypeScript + SVG (d3-geo) + Recharts. الخادم: FastAPI + SQLAlchemy (SQLite افتراضيًا، PostgreSQL اختياريًا).

> **تاريخ النظام المرجعي** يُؤخذ من ساعة الجهاز (يمكن تجاوزه بالمتغير `REFERENCE_DATE=2026-10-30` أو بالمعامل `?as_of=`).
> كل المراحل (قادم / يوم الاقتراع / انتهى) والأيام المتبقية تُحسب من هذا التاريخ ولا تُخزَّن كقيم ثابتة.

## البنية

```
backend/
  app/            FastAPI: main.py (المسارات) · service.py (بناء الحمولات) · models.py (النماذج) · db.py · config.py
  ingest/         fetch_sources.py  → ينزّل الملفات الخام إلى data/raw
                  build_dataset.py  → يحلّلها إلى data/processed/dataset.json (+ تقرير جودة)
                  load_db.py        → يحمّل في قاعدة البيانات مع حفظ التاريخ
                  update.py         → الثلاثة معًا + تسجيل الفشل
                  reference.py · arabic.py · wikitables.py
  tests/          pytest (سلامة البيانات + الـAPI + سلوك المحمِّل)
frontend/
  src/            App.tsx · model.tsx (ألوان/فلاتر الخريطة) · scenario.ts (+ scenario.test.ts) · components/
  public/data/    districts119.topo.json · districts120.topo.json  (حدود مبسّطة من الإحصاء الأمريكي)
tools/build_geo.py  يبني ملفات الحدود من shapefile (Node + mapshaper عبر npx)
data/             raw (ملفات مصدر مخزّنة) · processed/dataset.json · app.db (SQLite)
docker-compose.yml  PostgreSQL اختياري
```

## التثبيت والتشغيل

المتطلبات: Python 3.11+، Node 20+.

```bash
# 1) الخادم
cd backend
pip install -r requirements.txt
python ingest/load_db.py          # يحمّل data/processed/dataset.json الجاهز في قاعدة البيانات (SQLite)
python -m uvicorn app.main:app --port 8000

# 2) الواجهة (تطوير) في نافذة أخرى
cd frontend
npm install
npm run dev                       # http://localhost:5173  (يمرّر /api إلى :8000)
```

إنتاج: `cd frontend && npm run build` ثم شغّل uvicorn؛ يقدّم الخادم ملفات `frontend/dist` تلقائيًا على `http://localhost:8000`.

### PostgreSQL (اختياري)

```bash
docker compose up -d db
export DATABASE_URL=postgresql+psycopg2://usamap:usamap@localhost:5432/usamap
python backend/ingest/load_db.py
```
(الإعداد جاهز لكنه **لم يُجرَّب** في بيئة التطوير؛ المُجرَّب هو SQLite.)

### متغيرات البيئة
`DATABASE_URL` · `DATASET_PATH` · `FRONTEND_DIST` · `CACHE_TTL_SECONDS` (افتراضي 60، تخزين مؤقت للقطة قاعدة البيانات في الذاكرة) · `REFERENCE_DATE` · `STALE_AFTER_DAYS` (افتراضي 7). لا توجد مفاتيح API سرية في الواجهة؛ ولا يحتاج الاستيراد الحالي لأي مفتاح.

## تحديث البيانات

```bash
cd backend
python ingest/update.py     # جلب → تحليل → تحميل. ثم (اختياري) POST /api/admin/reload لإفراغ كاش الذاكرة
```
جدولة (مثلاً يوميًا): cron أو Windows Task Scheduler يشغّل الأمر أعلاه. **التحديث دوري/يدوي وليس لحظيًا**، والواجهة تقول ذلك صراحة.

عند فشل أي خطوة: لا تُمسّ بيانات قاعدة البيانات، وتُعلَّم كل المجموعات بـ `failed` مع الرسالة، ويُرجع الأمر رمز خروج غير صفري. تعرض الواجهة شريط تحذير وآخر تاريخ تحقق ناجح. تُعتبر المجموعة «متأخرة» إذا مرّ أكثر من `STALE_AFTER_DAYS` على آخر تحقق.

الاستبدال ببيانات أفضل: نموذج البيانات مفصول عن المصدر. لإضافة مصدر (مثل واجهة FEC بمفتاحك أو ملفات هيئات الولايات) عدّل `build_dataset.py` ليكتب السجلات نفسها (`candidacies` بحالة `declared` أو `potential` ومصدر ونوع بيانات) — يتولى `load_db.py` حفظ تاريخ تغيّر الحالة.

## كيف طُبّقت قواعد الدقة السياسية

- **شاغل المنصب ≠ مرشح**: موقف الشاغل (`running / retiring / term_limited / lost_primary / ...`) يأتي من حالة السباق في المصدر وليس من انتهاء الفترة؛ وعبارة «لم يُعلن موقفه» تعني `unknown` لا انسحابًا.
- **مقعد شاغر ≠ مقعد مفتوح**: `holdings.status = vacant` (لا شاغل، حاليًا مقعدان في النواب) مقابل `elections.is_open` (الشاغل لن يترشح).
- **الشيوخ**: 100 مقعد بفئاتها؛ المطروح في 2026 = 33 مقعدًا من الفئة 2 + انتخابان خاصان (فلوريدا وأوهايو) = 35. لا تُعدّ مقاعد الولاية كلها مطروحة.
- **المحتمل ≠ الرسمي**: `candidacies.status` = `declared | potential | withdrawn | not_listed`؛ وتعرضها الواجهة في أقسام منفصلة. **لا توجد حاليًا سجلات `potential`** (انظر القيود).
- **التنافسية ≠ نتيجة**: «تنافسي» يعني أن جهة خارجية واحدة على الأقل صنّفته Toss-up/يميل/يميل قليلًا. لا تُحوَّل التصنيفات إلى نسب.
- **الرسمي / التقديري / الافتراضي** منفصلة بصريًا (شارات `official/announced/estimate/hypothetical`) وفي ثلاثة أعمدة في وضع السيناريوهات.
- **تاريخ التغيّر**: جدول `candidacy_history` يضيف صفًا عند ظهور مرشح أو تغيّر حالته/حزبه؛ والمرشح الذي يختفي من المصدر يُعلَّم `not_listed` ولا يُحذف. تصنيفات الجهات تُضاف لكل (سباق، جهة، تاريخ نشر) فيبقى تاريخ التصنيفات.
- **الدوائر**: خريطتان — «الدوائر الحالية (119)» ملوّنة بحزب الممثل الحالي، و«خريطة 2026 (120)» ملوّنة بالحزب المدافع عن المقعد. كثير من الولايات غيّرت خرائطها بعد 2025، فلا تُعرض الحدود القديمة على أنها دوائر 2026.

## المحاكي والسيناريوهات (`frontend/src/scenario.ts`)

حساب مباشر بلا نماذج احتمالية:
- **الوضع الحالي**: توزيع المقاعد الرسمي (المستقلان اللذان يصوتان مع الديمقراطيين يُحتسبان ضمن كتلتهم وفق حقل `caucus` الرسمي).
- **الأساسي**: المقاعد المطروحة تتبع تصنيف **جهة واحدة تختارها**؛ Toss-up يبقى «غير محسوم»؛ ما لم تصنّفه الجهة يبقى للحزب الحالي/المدافع (افتراض حسابي مُعلَن). يُعرض المدى (أدنى/أعلى لكل حزب).
- **المحاكاة**: الأساسي + تعديلاتك مقعدًا مقعدًا أو عبر قوالب (كل المتقاربة لحزب، موجة افتراضية). تُحسب الأغلبية فورًا: الشيوخ 51، أو 50-50 فيحسمه حزب نائب الرئيس (ثابت قابل للتعديل `VICE_PRESIDENT_PARTY` في `reference.py`)؛ النواب 218 من 435.
- زر «إعادة المحاكاة إلى الأساسي» و«العودة إلى الوضع الحالي»، وتُعرض مقارنة الفرق عن الأساسي.

## الميزات غير المنفذة بالكامل وقيود البيانات (بصراحة)

1. **المرشحون المحتملون**: النموذج والواجهة يدعمانهما بقسم منفصل، لكن **لا مصدر في النسخة الحالية** (بعد انتهاء التمهيديات صارت القوائم نهائية) فيظهر القسم فارغًا برسالة توضيحية. لا نضيف أسماء غير موثّقة. وكذلك «لم يُعلن موقفه» نادر في هذه المرحلة.
2. **المرشحون الرسميون**: ولايتان فقط — **كاليفورنيا** (الحاكم و52 دائرة، 106 مرشحين) و**ميزوري** (8 دوائر، 24 مرشحًا) — وقد طابقت كل الأسماء المصدر الثانوي، مأخوذة مباشرة من وثيقة رسمية معتمدة وتظهر بعلامة «✓ قائمة رسمية». باقي الولايات من ويكيبيديا (مصدر ثانوي يستند إلى هيئات الولايات). FEC يُستخدم للربط بالمعرّفات فقط. جُرّبت ولايات كبرى أخرى ولم تتوفر بصيغة قابلة للاستيراد الآلي الموثوق:
   - **نيويورك**: موقع هيئة الانتخابات يرفض الطلبات الآلية (403).
   - **فلوريدا**: ملف تنزيل المرشحين الرسمي يعيد جدولًا فارغًا (حتى لانتخابات 2024) عند الطلب الآلي.
   - **تكساس**: لم أجد قائمة عامة معتمدة قابلة للتنزيل.
   - **كارولاينا الشمالية**: ملف الترشيحات الرسمي (CSV) يتضمن مرشحي التمهيدي (3 مارس) ومن سجّلوا للعام فقط، لا قائمة الاقتراع العام النهائية، فلا يصلح وحده (يلزم دمج نتائج التمهيدي).
   - **أوهايو وجورجيا وأيوا**: 403 للطلبات الآلية. **نيفادا**: وثيقة وزير الخارجية خلف حماية Incapsula ضد الروبوتات.
   - **داكوتا الجنوبية**: لم أجد وثيقة رسمية معتمدة (نتيجة بحث اتضح أنها لمقاطعة سان دييغو في كاليفورنيا فاستُبعدت).

   **سياسة الجلب**: يعرّف الجالب نفسه بوضوح (`usa-political-map`) ولا ينتحل متصفحًا ولا يتحايل على حماية الروبوتات؛ ما يُحجب يبقى على المصدر الثانوي حتى يتاح طريق مشروع (مفتاح/واجهة/اتفاق مع الجهة).

   لإضافة ولاية: أنشئ `backend/ingest/state_sources/<xx>.py` بالواجهة نفسها (`SOURCE` + `fetch()` + `parse()` يعيد `StateCandidate`) وسجّلها في `state_sources/__init__.py`. يتولى `build_dataset.py` المطابقة: الرسمي يتغلّب، والاسم غير المدرج رسميًا يصبح `not_listed` (لا يُحذف)، والمضاف/المختلف يُسجَّل. التنزيل يرفض الملفات المبتورة (مقارنة Content-Length).
3. **الانتخابات التمهيدية**: تواريخها متاحة لمقاعد مجلس الشيوخ فقط (35). لا تواريخ تمهيدية للحكام والنواب في المصادر المستوردة.
4. **حكام الولايات**: «تاريخ التولي» هو بدء الخدمة المتواصلة (ليس بالضرورة بداية الفترة الحالية)، ونهاية الفترة سنة فقط. **تاريخ تولي الحاكم الجديد غير متوفر** في المصادر فلا نخمّنه. مواعيد انتخابات الحكام خارج 2026 تُعرض كسنة فقط.
5. **الاحتمالات الرقمية**: لا تُستورد؛ «احتمال سيطرة كل حزب» يُعرض «غير متوفر». بعض الجهات (Silver Bulletin وEconomist وDDHQ) تنشر احتمالات لكنها غير مستوردة هنا.
6. **النتائج الرسمية**: لا تُستورد (الاقتراع 3 نوفمبر 2026). بعد التاريخ تعرض الواجهة «انتهى الاقتراع ولا نتائج رسمية في هذه النسخة» بدل افتراض فائز.
7. **أسماء عربية**: ≈55% من الأشخاص (321 من 589) و230 مرشحًا لهم اسم عربي؛ الباقي بالإنجليزية فقط.
8. **حدود الخريطة**: مبسّطة (قد تظهر فروق طفيفة عن الحدود التفصيلية)؛ الأقاليم (بورتوريكو وغوام...) ومندوبوها بلا شكل على الخريطة لكنهم في القوائم والإحصاءات الانتخابية. مندوب واشنطن العاصمة يظهر على الخريطة.
9. **خريطة 2026 والدائرة الحالية**: ربط «النائب الحالي ← سباقه في 2026» يعتمد على مطابقة الأسماء مع جدول ويكيبيديا؛ ما لم يُطابَق يُعرض «غير مرتبط» دون ادعاء الانسحاب. بعض الدوائر الجديدة بلا شاغل أو بأكثر من شاغل (12 دائرة) ولا حزب مدافع محدد لها فتُحتسب «غير محدد» في المحاكي إن لم تُصنَّف.
10. **التنافسية** حدّها الأدنى: تصنيف واحد (Lean أو أقرب) من أي جهة؛ ويمكن تغيير العتبة في `competitive_by` (service.py).
11. **PostgreSQL** مُعدّ ولم يُختبر؛ المُختبر SQLite.
12. بيانات الأعضاء من `congress-legislators` تتأخر عن الأحداث (آخر تحديث 5 أكتوبر 2026 عند البناء)؛ تُعرض مقارنة التواريخ في نافذة المصادر.
